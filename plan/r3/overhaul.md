# 기능
## 공용
### 질문 체계
- **질문 - 답변** 형태의 게시글 형태에서 서양식 포럼 형태로 개편.

### 레이아웃
- 스마트폰, 태블릿(+ 스마트폰 가로 모드, Z 폴드 시리즈 등), 데스크톱용 레이아웃을 구현.
- 눈이 편한 초록색조 테마를 추가.

### 전시용 계정 전환
- 사전 생성 계정을 없애고, 비로그인 / 로그인 상태 구분을 할 것.
  - 비로그인 시 헤더를 제외한 질문 영역이 흐려져 보이지 않도록 하고, 영역 위에 로그인 / 회원가입 안내를 표출.
- 전시를 위한 데모용의 회원가입 절차를 추가.
  - 학생 계정은 학번, 학과, 이름, ID, 비밀번호를 간단히 입력받도록 할 것.
  - 교수 계정은 학과, 담당 과목, 이메일, ID, 비밀번호를 간단히 입력받도록 할 것.

  - 계정 비밀번호는 적절한 해시 함수를 거치도록 할 것.
  - 코드 작성 시 보안에 각별히 유의할 것.
  - 각 계정의 정보를 토대로 중복 가입이 불가능하도록 할 것.

### 관리 모드
- 관리자 계정을 콘솔 등에서 특정 ID에 부여 가능하도록 할 것.

- 과목, 학과의 동적 추가가 가능하도록 할 것.
- 익명 질문의 질문자를 표시할 것.
- 질문, 답변을 가리기 (내용 비표시) 할 수 있도록 할 것.
- 일반 계정의 탈퇴, 질문 제한, 답변 제한을 할 수 있도록 할 것.
  - 탈퇴를 제외한 나머지에는 기간을 설정 가능하도록 할 것.

## 교수용

# 교수질문센터 - 교수와 학생 간 질답을 위한 서비스

<br>

# 사용할 기술

## 프론트엔드
- **React (v19) + Vite (v8)**: SPA 기반 UI 구축 및 번들링.
  - **Lucide React**: 아이콘 시스템.
  - **HTML5 Canvas API & Web Notification API**: 클라이언트 측 이미지 압축 및 브라우저 푸시 알림.
  - **LocalStorage 폴백 엔진**: 백엔드 미연결(정적 호스팅 등) 시에도 독립 동작 지원.

## 백엔드
- **Ktor (v2.3.12, Netty)**: 비동기 HTTP 서버 및 Ktor Client(CIO) 기반 외부 API 호출 담당.
  - **Exposed (v0.52.0)**: 백엔드에서의 데이터베이스와의 통신 담당.
  - **HikariCP (v5.1.0)**: 데이터베이스 커넥션 풀(Connection Pool) 관리.
- **PostgreSQL / H2 (PostgreSQL 호환 모드)**: 메인 데이터베이스 (`DB_URL` 미설정 시 인메모리 H2 자동 폴백).
- **Java AWT / ImageIO**: 서버 측 이미지 리사이징·압축 및 EXIF 메타데이터 제거.

## 데이터 및 배포
- **Python (`convert_xlsx_to_json.py`)**: 학사 개설과목 및 강의시간표 엑셀(`.xlsx`)을 `courses_data.json`으로 변환.
- **GCP (Nginx + Ktor) / Netlify**: 프로덕션 및 데모 배포 환경 대응.

# 기능
## 교수용
### 질문 알림
- 새 질문이 온 경우 알림 (알림함 및 브라우저 푸시 알림 지원).
- 알림을 받지 않을 시간대(방해 금지 시간대)를 설정 가능.
- **같은 과목 다른 교수** 기능 알림도 받을지 설정 가능.

### 같은 과목 다른 교수
- 특정한 과목을 강의하는 교수 모두가 해당 과목의 **강의** 카테고리 질문에 대해 답변 가능.
- 질문자의 담당교수가 답변을 남긴 경우 다른 교수는 답변 불가능.

### 카테고리별 질문 활성화/비활성화
- 과목·카테고리별로 해당 카테고리로의 질문이 가능할지를 설정 가능.

## 학생용
### 답변 알림
- 답변이 온 경우 알림.

### 익명 질문
- 질문자가 누구인지 다른 사람에게 표시되지 않음 (본인 질문에는 `(나)` 표기).
  - ex. `26_소프트_서영민` -> `공학설계입문 수강생`

### 질문 제목 생략 및 본문 요약
- 질문 작성·수정 시 별도의 제목 입력 없이 본문만 작성.
- 목록 등 제목 표시가 필요한 경우 본문의 첫 문장 또는 핵심 어구(최대 45자)를 자동 요약하여 제목 대신 사용.

### 파일 및 이미지 첨부
- 질문 작성 시 이미지 및 문서 파일 첨부 가능 (최대 5개, 파일당 최대 10MB).
- 확장자 화이트리스트·매직 바이트(Magic Bytes) 검사·경로 순회 방지 등 다중 보안 검증 적용.
- 대용량 이미지는 최대 1920px 다운스케일링 및 JPEG 0.82 품질 압축(EXIF 제거) 후 저장.

### AI 질문 도우미
- 학생이 입력한 질문 내용을 AI가 처리하여 말투나 표현 등을 교정·윤문.

#### 예시
원문: 
> 아니 교수야 성적이 이게 말이 되냐 차라리 재수강하게 C로 내려줘라
---
처리 후: 
> 안녕하십니까, [교수님 성함] 교수님. 이번 학기 [강의명]을 수강한 [학과] [학번] [이름]입니다. 한 학기 동안 열정적인 강의와 가르침을 주셔서 진심으로 감사드립니다. 다름이 아니라 이번 학기 최종 성적을 확인하였으나, 제가 예상했던 결과보다 다소 아쉬운 성적을 받게 되어 조심스럽게 문의를 드립니다. 혹시 제가 어떤 평가 항목에서 부족했는지 피드백을 여쭈어보아도 괜찮을지 여쭙고자 합니다. 아울러 현재 부여된 성적으로는 본교 규정상 추후 재수강을 통한 보완이 어려운 상황입니다. 만약 성적 상향이 어렵다면, 부족한 부분을 다시 성실히 공부하여 채울 수 있도록 재수강 요건에 맞추어 성적을 C0으로 조정해 주시는 것이 학칙상 가능한지 결례를 무릅쓰고 조심스레 여쭙습니다. 학기 말 바쁘신 일정 중에 번거로운 문의를 드려 송구합니다. 날씨가 쌀쌀한데 건강 유의하시기 바랍니다. 감사합니다.

#### 구현
- Google Gemini API(`gemini-2.5-flash` 우선, `gemini-2.0-flash` 폴백)를 백엔드에서 호출하여 서버의 직접 AI 연산 부담 없이 구현.
- API 키 미설정 또는 호출 실패 시 내장 규칙 기반 윤문 폴백 엔진으로 자동 대체.

### 유사 질답 보기
- 질문 시 기존에 질문과 답변이 이루어진 내용을 볼 수 있는 기능.

#### 구현
- 질문 등록 시 문자 2-gram 및 64차원 해시 투영 벡터를 사전 계산하여 저장.
- 유사 질답 조회 시 한국어 학술 불용어(Stopwords)를 제거한 뒤 어휘 및 문자 2-gram 기반 코사인 유사도를 계산하여 유사도 25% 이상인 상위 질문 및 답변을 판정·제공.

### 질문 카테고리
- 질문에 맞는 카테고리를 선택하여 카테고리별 기능을 사용 가능.
- 질문 시 카테고리 선택은 필수, 1개만 가능.

#### 카테고리
- 성적: 채점 기준이나 이의제기 등. 익명으로 질문 불가능. **유사 질답 보기**, **같은 과목 다른 교수** 기능 사용 불가.
- 과제: 과제 채점 기준이나 제출 형식 등. **같은 과목 다른 교수** 기능 사용 불가.
- 강의: 강의 내용에 대한 질문. 사용 불가능한 기능 없음.

## 공용
### 테마
- 글자 크기(작게, 보통, 크게, 아주 크게) 및 라이트/다크 테마 설정 가능.

### 전시용 계정 전환
- 우측 상단 계정 선택 창을 통해 사전 설정된 학생/교수 계정 간 빠른 전환 지원 (프로덕션 환경에서는 `ENABLE_DEMO_USERS` 설정으로 제어).

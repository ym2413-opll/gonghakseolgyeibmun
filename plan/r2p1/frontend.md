# 프론트엔드

<br>

# 사용할 기술
- **React (v19) + Vite (v8)**
- **Lucide React**: UI 아이콘 시스템.
- **HTML5 Canvas API & FileReader/DataView**: 업로드 전 클라이언트 측 이미지 다운스케일링(최대 1920px, JPEG 0.82 압축) 및 파일 시그니처(매직 바이트) 사전 검증.
- **Web Notification API**: 브라우저 푸시 알림.
- **LocalStorage 오프라인 폴백 엔진**: 백엔드 미연결(정적 호스팅 등) 시 자체 mock 데이터 및 유사도 연산으로 동작 지원.

# 플랫폼
- 웹 (Desktop / Mobile 2종 반응형 자동 감지: 화면 너비 `768px` 이하 시 모바일 레이아웃 및 `BottomNav` 하단 내비게이션 자동 전환).
- 안드로이드 애플리케이션 (모바일 웹 반응형 기반, 네이티브 패키징 전 단계).

# 기능
## 교수용
### 질문 알림
- 새 질문이 온 경우 알림함 뱃지·드롭다운 및 브라우저 푸시 알림 표시.
- 알림을 받지 않을 시간대(방해 금지 시간대)를 설정 가능 (`NotificationSettingsModal`).
  - **이 설정 값을 백엔드로 보내어 백엔드에 처리를 위임함.**
- **같은 과목 다른 교수** 기능 알림도 받을지 설정 가능.
  - **이 설정 값을 백엔드로 보내어 백엔드에 처리를 위임함.**

### 같은 과목 다른 교수
- 특정한 과목을 강의하는 교수 모두가 해당 과목의 **강의** 카테고리 질문에 대해 답변 가능.
- 질문자의 담당교수가 답변을 남긴 경우 다른 교수는 답변 불가능 (`AnswerForm` 입력 차단 안내).
  - **질문 열람 시 백엔드에서 답변 존재 여부 및 답변 가능 여부(`canAnswer`, `isAnsweredByAssignedProfessor`)를 가져와 제어함.**

### 카테고리별 질문 활성화/비활성화
- 과목·카테고리별로 해당 카테고리로의 질문이 가능할지를 설정 가능 (`CategorySettingsModal`).
  - **이 설정 값을 백엔드로 보내어 백엔드에 처리를 위임하며, 학생 질문 작성 창에서 비활성화 상태를 실시간 반영함.**

## 학생용
### 답변 알림
- 답변이 온 경우 알림함 및 브라우저 푸시 알림 표시.

### 익명 질문
- 질문자 정보는 백엔드로 전송하되, 익명 질문이더라도 익명 처리되지 않은 원본 사용자 식별 정보를 보냄.
  - 조회 화면에서는 타인에게 익명 마스킹되어 표시됨 (본인 질문에는 `(나)` 표시).
  - ex. `26_소프트_서영민` -> `공학설계입문 수강생`

### 질문 제목 생략 및 본문 요약
- 질문 작성(`QuestionForm`) 및 수정(`QuestionDetail`) 화면에서 별도의 제목 입력란을 제거.
- 목록 카드(`QuestionCard`) 등 제목 표시가 필요한 경우 본문의 첫 문장 또는 핵심 어구(최대 45자)를 규칙 기반으로 자동 요약(`textSummary.js`)하여 표시.

### 파일 및 이미지 첨부
- 드래그 앤 드롭 및 파일 선택으로 이미지·문서 첨부 지원 (최대 5개, 파일당 최대 10MB).
- 업로드 전 클라이언트 측에서 1차 보안 검증(`fileSecurity.js`: 확장자 화이트리스트·이중 확장자·매직 바이트 검사) 및 대용량 이미지 자동 압축(`imageCompression.js`) 수행 후 멀티파트 전송.
- 질문 상세 화면에서 첨부파일 목록·다운로드 및 이미지 확대 모달 제공.

### AI 질문 도우미
- 학생이 입력한 질문 내용을 AI가 처리하여 말투나 표현 등을 교정·윤문 (`AiRefineModal`, 전시용 퀵 템플릿 포함).
- **백엔드에 원문으로 요청 후 응답으로 AI가 순화한 내용을 받고, 원문과 교정본을 나란히 비교하여 질문자(=사용자)의 직접 확인·선택을 거치게 함.**

### 유사 질답 보기
- 질문 작성 중(6자 이상 입력, 400ms 디바운싱) 기존에 질문과 답변이 이루어진 유사 내용을 실시간 탐색·표시 (`SimilarQuestionsModal` 및 작성 화면 내 추천 영역).

#### 구현
- **백엔드 유사도 조회 API 요청 시 백엔드에서 유사도 상위 N개 질문(유사도 % 및 답변 스니펫 포함)으로 응답받아 표시.**
- **백엔드 오프라인 시 클라이언트 내장 동적 토큰 빈도(TF) + 문자 2-gram 코사인 유사도(`wordSimilarity.js`)로 자체 계산.**

### 질문 카테고리
- 질문에 맞는 카테고리를 선택하여 카테고리별 기능을 사용 가능.
- 질문 시 카테고리 선택은 필수, 1개만 가능.

#### 카테고리
- 성적: 채점 기준이나 이의제기 등. 익명으로 질문 불가능. **유사 질답 보기**, **같은 과목 다른 교수** 기능 사용 불가.
- 과제: 과제 채점 기준이나 제출 형식 등. **같은 과목 다른 교수** 기능 사용 불가.
- 강의: 강의 내용에 대한 질문. 사용 불가능한 기능 없음.

## 공용
### 테마
- 글자 크기(작게, 보통, 크게, 아주 크게) 및 라이트/다크 테마 설정 가능 (`SettingsModal`, 헤더 간편 테마 전환 버튼).
  - **설정을 백엔드에 보내어 저장하고, 페이지 최초 로드 시 백엔드에 설정 값을 요청하여 받아옴.**

### 전시용 계정 전환 및 안정성
- 우측 상단 포털 프로필 드롭다운(`Header.jsx`)을 통해 사전에 설정된 학생/교수 계정 중 하나를 선택하여 즉시 전환 가능 (초기화 버튼은 제거됨).
- `ErrorBoundary`를 통한 예기치 못한 렌더링 오류 복구 지원.

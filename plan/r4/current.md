# 교수질문센터 - 교수와 학생 간 질답을 위한 서비스

<br>

# 사용할 기술

## 프론트엔드
- **React**: React 19, Vite, Lucide React 기반 단일 페이지 웹 애플리케이션.

## 백엔드
- **Ktor**: Kotlin, Netty, Coroutines 백그라운드 워커 기반 API 서버 및 비동기 작업 처리.
  - **Exposed** + **HikariCP**: 백엔드에서의 데이터베이스 연동 및 커넥션 풀 관리.
- **PostgreSQL** / **H2**: 운영 및 개발/테스트용 관계형 데이터베이스.
- **Google Gemini API**: 질문 윤문 및 제목 요약 처리 (미설정 시 규칙 기반 폴백 지원).
- **Resend API / SMTP & Jakarta Mail (IMAP)**: 이메일 발송 및 회신 수신 폴링·웹훅 연동.

# 기능
## 교수용
### 대시보드 및 질문 조회
- `내 담당 질문`, `타 교수 강의 질문`, `전체 질문` 탭으로 구분하여 조회 가능.
- 카테고리, 답변 상태(`전체` / `미답변` / `답변 완료`), 키워드 검색 필터 제공.

### 질문 알림 및 이메일 연동
- 새 질문 및 후속 질문 등록 시 인앱 알림과 브라우저 알림 제공.
- 방해 금지 시간대(DND)를 설정하여 해당 시간 동안 알림 보류 후 종료 시점에 일괄 발송.
- **같은 과목 다른 교수** 기능 알림 수신 여부 설정 가능.
- 카테고리(`성적`, `과제`, `강의`)별 알림 수신 활성화/비활성화 설정 가능.
- 이메일 수신 주소를 선택적으로 등록할 수 있으며(전시용 계정 전환에 따라 필수 입력 아님), 수신한 알림 메일에 회신(`POST /api/webhooks/email-reply` 또는 IMAP 폴링) 시 해당 스레드에 답변 자동 등록.

### 스레드 공개 범위 전환 (열림 / 닫힘)
- 담당 교수가 각 질문 스레드의 공개 범위를 `닫힘`(최초 질문자와 담당교수만 작성 가능)과 `열림` 상태로 전환 가능.
- `열림` 상태에서는 **같은 과목 다른 교수** 답변 및 다른 수강생의 답변 작성을 허용.

### 같은 과목 다른 교수
- 스레드가 `열림` 상태일 때 동일 교과목을 담당하는 다른 분반 교수도 답변 작성 가능.
- 질문자의 담당교수가 공식 답변을 등록하면 다른 교수의 추가 답변은 제한됨.

### 학생 답변 관리
- `열림` 상태 스레드에 다른 학생이 남긴 답변을 담당교수가 가리기/가리기 해제 또는 삭제 가능.

### 담당 교과목 설정
- 교수 회원가입 시 및 설정 창에서 담당 교과목을 다중 선택하고 변경 저장 가능.

## 학생용
### 답변 알림
- 교수, 관리자 또는 다른 학생의 답변이 등록되면 알림 수신.

### 익명 질문
- `성적` 외 카테고리에서 질문자가 누구인지 다른 학생에게 표시되지 않도록 익명으로 작성 가능.
  - ex. `26_소프트_서영민` -> `수강생`
- 익명 질문이라도 담당교수 및 관리자 화면에서는 학사 관리와 책임성 확보를 위해 실제 이름과 학번이 표시됨.

### AI 질문 도우미
- 학생이 입력한 거친 원문을 AI가 정중한 어투로 윤문하고 핵심 제목을 생성.
- 윤문 적용 시 원문도 함께 저장되어 교수 열람 화면에서 `원문 보기`로 확인 가능.

#### 예시
원문:
> 아니 교수야 성적이 이게 말이 되냐 차라리 재수강하게 C로 내려줘라
---
처리 후:
> 안녕하십니까, 교수님. 이번 학기 강의를 성실히 수강한 학생입니다. 한 학기 동안 열정적인 강의와 가르침을 주셔서 진심으로 감사드립니다. 다름이 아니라 이번 학기 최종 성적을 확인하였으나, 제가 예상했던 결과보다 다소 아쉬운 성적을 받게 되어 조심스럽게 문의를 드립니다. 혹시 제가 어떤 평가 항목에서 부족했는지 피드백을 여쭈어보아도 괜찮을지 여쭙고자 합니다. 아울러 현재 부여된 성적으로는 본교 규정상 추후 재수강을 통한 보완이 어려운 상황입니다. 만약 성적 상향이 어렵다면, 부족한 부분을 다시 성실히 공부하여 채울 수 있도록 재수강 요건에 맞추어 성적을 C0으로 조정해 주시는 것이 학칙상 가능한지 결례를 무릅쓰고 조심스레 여쭙습니다. 학기 말 바쁘신 일정 중에 번거로운 문의를 드려 송구합니다. 감사합니다.

#### 구현
- Google Gemini API 호출 및 API 키 미설정·오류 시 규칙 기반 윤문·요약 폴백으로 동작.

### 유사 질답 보기
- 질문 입력 중 동일 과목 내에서 유사한 기존 질문과 답변을 실시간으로 추천.

#### 구현
- 한국어/영문 토큰, 바이그램, 자모 N-gram 코사인 유사도를 결합하여 유사한 기존 질문과 답변을 판정(`SimilarityService` / `wordSimilarity.js`).

### 질문 카테고리
- 질문에 맞는 카테고리를 선택하여 카테고리별 정책을 적용.
- 질문 시 카테고리 선택은 필수이며 1개만 선택 가능.

#### 카테고리
- 성적: 채점 기준이나 이의제기 등. 익명 질문 불가, **유사 질답 보기** 및 **같은 과목 다른 교수** 기능 사용 불가.
- 과제: 과제 채점 기준이나 제출 형식 등. 익명 질문 및 **유사 질답 보기** 가능, **같은 과목 다른 교수** 기능 사용 불가.
- 강의: 강의 내용에 대한 질문. 사용 불가능한 기능 없음.

### 수강 과목 설정
- 학생 회원가입 시 및 설정 창에서 수강 과목을 다중 선택하고 변경 저장 가능.

## 관리자용
### 권한 부여 및 보안
- 브라우저나 HTTP API를 통한 관리자 권한 부여는 차단되며, 백엔드 서버 콘솔 또는 로컬 루프백 제어 소켓의 `admin <ID 또는 학번>`, `revoke-admin <ID 또는 학번>` 명령어로만 권한 부여·해제 가능.

### 학과 및 과목 동적 관리
- 관리자 화면(`AdminModal`)에서 단과대별 신규 학과 추가(고유번호 자동/수동 부여) 및 전공·교양 교과목 추가 가능.

### 계정 제재 및 복구
- 가입 계정 목록 조회 및 강제 탈퇴/복구 처리.
- 특정 계정의 질문 금지 또는 답변 금지 기간(시간 단위) 설정 및 해제 가능.

### 게시글 관리 및 스레드 참여
- 관리자는 모든 질문 스레드에 참여하여 `관리자` 고유 식별 배지가 붙은 답변 작성 가능.
- 질문 및 답변의 가리기/가리기 해제, 영구 삭제 처리 가능.
- 전체 이메일 발송 로그 조회 가능.

## 공용
### 포럼형 스레드 및 불변 순번·앵커
- 최초 질문을 `#1`로 시작하여 후속 답변마다 `#2`, `#3`... 순번을 순차 부여.
- 중간 답변이 가려지거나 삭제되어도 `lastSequenceNumber` 기반으로 각 포스트의 고유 순번은 변하지 않음.
- 본문 내 `#n` 형식의 앵커를 클릭하면 해당 순번 포스트로 스크롤 이동 및 강조 표시.

### 첨부파일 및 인라인 이미지
- 최대 15MB, 허용 확장자 화이트리스트(`png`, `jpg`, `jpeg`, `gif`, `webp`, `pdf`, `docx`, `doc`, `xlsx`, `xls`, `pptx`, `ppt`, `hwp`, `hwpx`, `txt`, `zip`)와 다중 확장자·매직 바이트 검증 적용.
- 업로드된 이미지는 백그라운드 워커가 최대 1920px 해상도·JPEG 품질 압축 처리.
- 본문 내 `[사진 k]` 구문을 작성하면 첨부 이미지 중 `k`번째 이미지를 해당 문단 위치에 인라인 렌더링.

### 학과 고유번호 및 학번 체계
- 학과 고유번호는 `(단과대 1자리: 1~9)(단과대 내 학과 2자리: 01~99)`의 3자리 숫자로 구성되며 각 번호는 1부터 시작.
- 학생 학번은 `(연도 4자리)(단과대 1~9 + 학과 01~99)(순번 3자리: 일반 001~500, 외국인 501~999)` 형식의 10자리 숫자 규칙을 적용(선택한 학과 고유번호와 일치 여부 대신 학번 형식만 검증).
- 회원가입 시 학생 학번은 `직접 입력`을 기본으로 하며, 설정 창에서 `전시 모드`를 켜면 학번 입력칸 옆에 미사용 순번을 무작위로 채우는 `무작위 생성` 버튼을 노출(`GET /api/auth/next-student-id?random=true`).

### 사용 도움말
- 계정별 첫 회원가입 시 도움말 수준을 선택하는 온보딩 팝업 노출.
- `필요 없음`, `조금`(핵심 기능), `모두`(전체 기능) 3단계로 나뉘며 설정 창에서도 언제든 변경 가능.
- `-해요`체 설명이 담긴 말풍선 형태로 각 기능 요소 옆에 표시되며 개별 접기/펼치기 지원.

### 테마 및 환경 설정
- 밝기(라이트 / 다크)와 배색(무채색 / 초록) 조합의 4종 테마 전환 지원.
- 글자 크기(`작게`, `보통`, `크게`, `아주 크게`) 4단계, 도움말 수준(`필요 없음`, `조금`, `모두`), `전시 모드`(`꺼짐`, `켜짐`) 설정 제공.

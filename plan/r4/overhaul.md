# 교수질문센터 - 교수와 학생 간 질답을 위한 서비스 <sub>체계개편안</sub>

<br>

# 기능
## 공용
### 질문 체계
- 스레드 내 순번을 이용하여 특정한 위치를 가리킬 수 있는 앵커 기능을 추가. (#1부터 최초 질문, 구문은 #(n) 형식으로. 번호의 validation에 유의할 것. 특정한 질답이 가리기 또는 삭제되어도 고유 순번은 불변.)
- 인라인 이미지 기능을 추가. (구문은 `[사진 1]` 형식으로. 첨부 파일 내 이미지 파일의 목록에서.)
- 스레드를 담당 교수가 `질문자, 담당교수 외 닫힘`, `열림` 여부를 전환 가능하도록 할 것. `열림` 상태에서 가능한 기능은 다음과 같음.
  - 같은 과목 다른 교수 기능.
  + 최초 질문자를 제외한 학생이 답변을 남길 수 있음. 이때, 학생의 답변은 담당교수가 가리기 또는 삭제 가능.

### 전시용 계정 전환
- 교수 계정의 이메일 필수 기입 조건을 없앨 것.
- 학생의 학번은 (연도 4자리)(학과 고유번호 3자리)(앞 7자리가 같은 집단 내 순번, 001부터 시작, 외국인 학생은 501부터 시작) 규칙을 따름.

### 관리 모드
- 관리자는 모든 스레드에 글을 쓸 수 있도록 할 것.
  - 스레드 내에서 고유 식별 표지를 가질 것.

### 사용 도움말
- 계정별 첫 회원가입 시 팝업으로 도움말의 필요를 설정 가능한 창을 띄울 것.
- 도움말의 필요는 `필요 없음`, `조금` (주요 기능에 대한 도움말), `모두` (모든 기능 요소에 대한 도움말) 3가지로 나눌 것.
- 내용은 `help.txt`를 기초로 할 것.
- 디자인은 각 기능 요소에 말풍선 형태로 붙인 것으로 할 것.
- 도움말의 필요는 설정 창에서도 바꿀 수 있도록 할 것.

# 교수질문센터 - 교수와 학생 간 질답을 위한 서비스 <sub>r3에서의 문제 수정</sub>

<br>

# 기능
## 공용
### 헤더
- 설정 버튼이 제대로 작동하지 않음.

### 레이아웃
- ID, 비밀번호 입력 폼 등에 스타일이 적용되지 않아 이질감이 있음.
- 쓸데없이 추가된 사족성 설명들이 너무 많음.
- 일부 아이콘과 정렬이 맞지 않는 텍스트를 수정할 것.
- 설정 버튼을 누를 시 포럼 창 밑에 깨진 설정 창이 표시되는 문제를 수정할 것.

### 전시용 계정 전환
- 학생 계정의 ID를 학번으로 대체할 것.
- 교수의 담당 과목 설정에 스크롤 리스트를 적용하고, 검색 기능을 추가할 것.
- 비로그인 시 로그인 / 회원가입 안내 창을 최대한 간결히 하여 로그인 / 회원가입 페이지로 가는 페이지 버튼만 넣을 것.

### 관리 모드
- 관리자 계정 부여를 systemd에서의 구동 상태에서도 콘솔 등으로 가능하게 할 것.
- 관리자 계정에 글 삭제 기능을 추가할 것.

## 학생용
### AI 질문 도우미
- AI 질문 도우미가 학생 이름을 교수 이름에 넣는 등의 문제를 수정할 것. (관련 정보 일부, 예시로 학생과 교수의 이름을 AI의 프롬프트에 넣을 것.)

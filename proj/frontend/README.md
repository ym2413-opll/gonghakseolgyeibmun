# 교수질문센터 (Professor Question Center) - Frontend

교수와 학생 간의 질답을 위한 대학 학사 질답 포털 웹/앱 프론트엔드 프로젝트입니다.
`plan/r2/` 기획 명세서(`main.md`, `frontend.md`, `backend.md`)에 정의된 요구사항을 바탕으로 개발되었습니다.

---

## 📌 주요 기능 구현 현황

### 1. 🎓 학생용 기능 (Student Features)
- **질문 카테고리 (필수 1개 선택)**:
  - **성적**: 채점 기준 및 이의제기 문의.
    - 🔒 **익명 질문 불가** (실명 필수, 공정한 학사 관리용).
    - 🔒 **유사 질답 보기 불가**.
    - 🔒 **같은 과목 다른 교수 답변 불가** (담당 교수만 답변 가능).
  - **과제**: 과제 채점 기준 및 제출 형식 등.
    - ✅ **익명 질문 가능** (`[과목명] 수강생` 표기).
    - ✅ **유사 질답 보기 가능**.
    - 🔒 **같은 과목 다른 교수 답변 불가** (분반별 기준 상이 방지).
  - **강의**: 강의 내용 및 이론/실습 질문.
    - ✅ **익명 질문 가능**.
    - ✅ **유사 질답 보기 가능**.
    - ✅ **같은 과목 다른 교수 답변 가능** (학생의 빠른 피드백 지원).
- **익명 질문 시스템**:
  - 학생 화면 및 전체 질문 목록에는 `공학설계입문 수강생`으로 안전하게 익명 표기 (질문자 본인에게는 익명 뱃지 표시).
  - 백엔드 전송 시에는 명세대로 **익명 처리되지 않은 원본 학생 정보(학번, 성명, 학과)**를 함께 전송하여 서버 측 무분별한 악용 방지.
- **✨ AI 질문 도우미**:
  - 학생이 격양되거나 거친 표현, 비격식 어조로 작성한 내용을 대학 학술 문의 표준 양식 및 공손한 존댓말로 교정·윤문.
  - **명세 준수**: AI 교정본을 바로 자동 대체하는 것이 아니라, **[원문] vs [AI 추천 교정본]을 나란히 비교하여 학생 사용자의 직접 확인 및 선택(적용/수정/원문 유지)**을 거침.
  - 전시용 퀵 템플릿 포함 (`"아니 교수야 성적이 이게 말이 되냐 차라리 재수강하게 C로 내려줘라"` 등 원클릭 입력).
- **🔍 유사 질답 보기 (Word2Vec & 코사인 유사도)**:
  - 질문 작성 시 입력된 텍스트의 키워드 및 n-gram 벡터를 계산하여, 기존 완료된 질문들과의 코사인 유사도 상위 n개(유사도 점수 %) 랭킹 제공.
  - 학생이 질문을 등록하기 전 기존 답변을 미리 확인하여 즉각 의문을 해결할 수 있도록 지원.

### 2. 👨‍🏫 교수용 기능 (Professor Features)
- **질문 알림 및 제어**:
  - 새 질문 접수 시 실시간 알림 뱃지 및 알림함 제공.
  - **방해 금지 시간대 설정**: 알림을 받지 않을 시간대(예: 22:00 ~ 08:00) 설정 시 백엔드로 설정값을 전송하여 푸시 보류 처리.
  - **'같은 과목 다른 교수' 알림 수신 토글**: 동료 교수의 강의 질문 알림 수신 여부 설정.
- **카테고리별 질문 활성화/비활성화**:
  - 학기 운영 일정(성적 정정 마감 등)에 맞춰 [성적 / 과제 / 강의] 카테고리 접수 상태를 개별 ON/OFF.
  - 비활성화 시 학생 질문 작성 화면에서 해당 카테고리가 실시간 비활성화 처리됨.
- **'같은 과목 다른 교수' 답변 권한 로직**:
  - 질문 열람 시 백엔드로부터 답변 존재 여부를 조회.
  - 질문 카테고리가 **강의**이고, 담당 교수가 아직 답변하지 않은 경우 **동일 과목의 다른 교수도 답변 작성 가능**.
  - 담당 교수가 이미 답변을 완료한 경우 타 교수의 추가 답변 작성 차단.
  - 성적 및 과제 카테고리는 담당 교수 외 답변 권한 원천 차단.

### 3. 🌐 공용 및 전시용 특화 기능 (Showcase Mode)
- **전시용 계정 즉시 전환 (Demo Bar)**:
  - 학생 (`26_소프트_서영민`, `25_컴공_김민지`)
  - 교수 (`이교수 - 공학설계입문 주담당`, `박교수 - 공학설계입문 공동강의`, `정교수 - 자료구조 담당`)
  - 헤더 상단 툴바에서 원클릭으로 학생/교수 역할을 스위칭하여 각 역할별 화면과 권한 즉시 시연 가능.
- **플랫폼 뷰 전환 (🖥️ 데스크톱 웹 ↔ 📱 모바일/안드로이드 앱)**:
  - 데스크톱 포털 뷰와 스마트폰 프레임(안드로이드 모바일 앱 레이아웃 및 하단 탭바) 간의 즉각 전환 뷰어 내장.
- **테마 및 화면 설정 (Theme & Font Size)**:
  - 라이트 모드 / 다크 모드 전환.
  - 글자 크기(작게, 보통, 크게, 아주 크게) 조절.
  - 최초 로드 시 백엔드에서 설정값을 가져오고, 변경 시 백엔드에 즉시 동기화.
- **하이브리드 백엔드 연동 아키텍처**:
  - 실제 Ktor 백엔드 서버(`http://localhost:8080`) 통신 규격 완비.
  - 전시회나 발표 환경에서 백엔드가 오프라인이어도 끊김 없이 시연 가능한 스마트 Mock 백엔드 Fallback 엔진 내장.
